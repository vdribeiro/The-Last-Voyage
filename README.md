# The Last Voyage

The Last Voyage is an Educational Space Adventure born out of an astronomy tool.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/I2I81J9XQL)

## Development Board
You can track the development [here](https://mammoth-gallium-e97.notion.site/The-Last-Voyage-2420fa355a5080da91ffd9262f430feb).

## Supported Platforms
* Android
* iOS
* Windows
* macOS
* Linux

## Tech Stack
- UI: [Compose Multiplatform](https://github.com/JetBrains/compose-multiplatform)
- Database: [SQLDelight](https://cashapp.github.io/sqldelight/)
- Networking: [Ktor](https://ktor.io/)
- Monitoring: [Sentry](https://sentry.io/)
- Code Coverage: [Kover](https://github.com/Kotlin/kotlinx-kover)
